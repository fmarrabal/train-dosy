# Manuscript v2 / Revisión del manuscrito v2

## English

This documentation revision expands the Mathematics draft from 23 to 48 references, with four additional publications coauthored by Arrabal-Campos and 21 references on inversion, regularization, identifiability, spectral unmixing and learned reconstruction. It integrates them into the argument and adds a related-work section. All 48 references are cited; 46 DOI records are archived, alongside two software citations.

MF is defined consistently as **multifrequency**, following the historical source header. Nonnegative matrix factorization describes its mathematical implementation. The later constrained reference and the original TRAIn-derived V3.1 solver remain explicitly distinguished.

The numerical software is still **v0.1.0**. No algorithm, benchmark metric, example result or scientific figure was changed. The original v0.1.0 tag and release remain available. This release supplies the revised PDF and a complete source archive, including the existing MATLAB, Python, API, C# client and examples.

Validation covers DOI/citation consistency, three-pass LaTeX compilation, PDF visual review, the 22 preserved source hashes, and byte comparisons of frozen numerical materials with v0.1.0. It does not constitute a new solver benchmark. Author metadata and declarations remain pending; this is an unsubmitted research draft. GitHub Actions remain disabled.

See [bibliographic selection and corrections](BIBLIOGRAPHY_EN.md) and the machine-readable evidence in `paper/evidence/bibliography_audit.json` and `verification/paper_audit.json`.
