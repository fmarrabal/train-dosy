# TRAIn-MF / Manuscript v3

The distributional algorithm is now named **TRAIn-MF** throughout the manuscript, DOSY figure, English/Spanish README and current documentation. MF denotes multifrequency processing; its model is a nonnegative matrix factorization. The numerical reference and its source lineage remain unchanged.

For compatibility, the API/CLI identifier remains `MF-AUTO`, and the MATLAB function remains `DOSY_MF_Auto`. The historical `TRAIn_DOSY_MFV31.m` file retains its original name and bytes. The repository continues to contain RAI-S and DOME-S alongside TRAIn-MF.

Only presentation changes: no solver refitting, no changes to data, estimates, component selection, penalties or benchmark metrics. The DOSY panel title changes to TRAIn-MF, and its export bounds include the entire colorbar label. The 48 references remain unchanged. Software version 0.1.0 is retained; the manuscript revision is `manuscript-v3`. Earlier releases remain available. GitHub Actions remains disabled.
